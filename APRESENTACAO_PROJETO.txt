📋 VISÃO GERAL
================================================================================

Sistema web para análise automatizada de Eletrocardiogramas (ECG) e 
Hemogramas Completos, desenvolvido com FOCO em ACESSIBILIDADE 
para médicos com deficiência visual.

DIFERENCIAL:
→ Integração com banco de dados para conversão de laudos de TEXTO para ÁUDIO.
→ Navegação acessível por teclado.
→ Feedback auditivo para as interações
→ Autonomia  na interpretação de exames

⚡ FUNCIONALIDADES CLÍNICAS
================================================================================

1. ANÁLISE DE ELETROCARDIOGRAMA (ECG)
   ───────────────────────────────────

   O sistema interpreta dados de ECG e gera laudos completos incluindo:

   • Análise de Ritmo e Frequência
     - Classificação do ritmo cardíaco (sinusal, FA, flutter, BAV)
     - Avaliação da frequência (bradicardia, normal, taquicardia)

   • Intervalos e Condução
     - Intervalo PR (detecção de bloqueios atrioventriculares)
     - Duração do QRS (bloqueios de ramo)
     - Intervalo QT/QTc corrigido

   • Eixo Elétrico Cardíaco
     - Cálculo e interpretação do eixo no plano frontal
     - Identificação de desvios patológicos

   • Morfologia das Ondas
     - Onda P (sobrecargas atriais)
     - Complexo QRS (sobrecargas ventriculares, ondas Q patológicas)
     - Segmento ST e Onda T (isquemia, lesão, infarto)

   • Diagnósticos Específicos
     - Bloqueios de condução (AV, ramo direito, ramo esquerdo)
     - Isquemia miocárdica e localização anatômica
     - Infarto agudo do miocárdio
     - Sobrecargas cavitárias

   • Casos Clínicos Prontos para Demonstração
     - ECG Normal (FC 75bpm, ritmo sinusal regular)
     - Fibrilação Atrial com resposta ventricular rápida
     - Infarto agudo anterior (supradesnível ST em V1-V4)

2. ANÁLISE DE HEMOGRAMA COMPLETO
   ──────────────────────────────

   Interpretação completa com valores de referência validados:

   • Série Vermelha (Eritrograma)
     - Hemácias, Hemoglobina, Hematócrito
     - Índices: VCM, HCM, CHCM, RDW
     - Classificação de anemias por morfologia:
       → Microcítica (VCM < 80 fL): deficiência de ferro, talassemia
       → Macrocítica (VCM > 100 fL): deficiência B12/folato
       → Normocítica: perda aguda, doença crônica

   • Série Branca (Leucograma)
     - Contagem total de leucócitos
     - Contagem diferencial completa
     - Interpretação de desvios:
       → Neutrofilia: infecções bacterianas
       → Linfocitose: infecções virais, leucemias
       → Eosinofilia: alergias, parasitoses
       → Monocitose: infecções crônicas

   • Plaquetas
     - Contagem e interpretação clínica
     - Plaquetopenia e plaquetose
     - Correlação com quadro clínico

   • Valores de Referência
     - Baseados em estudos com mais de 100.000 indivíduos
     - Diferenciados por sexo (masculino/feminino)
     - Sistema de flags automático (Normal/Alto/Baixo)

   • Casos Clínicos para Demonstração
     - Hemograma normal
     - Anemia ferropriva
     - Leucocitose com neutrofilia (infecção bacteriana)
     - Plaquetopenia
     - Leucopenia pós-quimioterapia
     - E outros...

3. SISTEMA DE ÁUDIO PARA LAUDOS
   ─────────────────────────────

   • Conversão  de laudos em áudio narrado
   • Laudos de áudio concisos (informações essenciais)
   • Player com controles simples (play, pause)
   • Geração rápida (poucos segundos)

4. RECURSOS DE ACESSIBILIDADE
   ───────────────────────────

   • Navegação Completa por Teclado
     - Sem necessidade de mouse
     - Atalhos numéricos intuitivos (0-9)
     - Teclas de função (/, *, -, +)

   • Feedback Auditivo
     - Anúncios de todas as ações realizadas
     - Confirmação de análises concluídas
     - Alertas de erros e avisos
     - Função para repetir último anúncio (*)

   • Interface Visual Otimizada
     - Alto contraste
     - Fontes grandes e legíveis
     - Espaçamento adequado entre elementos
     - Cores com significado clínico (vermelho/verde/amarelo)

   • Compatibilidade Total
     - Funciona com leitores de tela (NVDA, JAWS, VoiceOver)
     - Responsivo (desktop, tablet, smartphone)
     - Acessível via navegador web comum

💻 COMO FUNCIONA NA PRÁTICA
================================================================================

FLUXO DE TRABALHO:
─────────────────

1. Acesso ao Sistema
   → Abrir navegador web (qualquer dispositivo)
   → Acessar a aplicação localmente ou via servidor

2. Escolha do Tipo de Exame
   → Pressionar "1" para ECG
   → Pressionar "2" para Hemograma
   → Sistema anuncia as opções via áudio

3. Entrada de Dados
   → Preencher campos do exame (com navegação por teclado)
   → OU carregar exemplo pronto para demonstração
   → Sistema valida dados em tempo real

4. Análise Automática
   → Processamento imediato dos dados
   → Motor de análise aplica critérios clínicos validados
   → Geração de laudo estruturado

5. Resultado
   → Laudo completo exibido em texto
   → Áudio narrado gerado automaticamente
   → Opções: ouvir, copiar, salvar

VANTAGENS OPERACIONAIS:
──────────────────────
• Análise em segundos (vs minutos manualmente)
• Padronização de laudos
• Redução de erros de interpretação
• Documentação automática
• Acessível 24/7
• Sem necessidade de treinamento extenso

⌨️ NAVEGAÇÃO SIMPLIFICADA
================================================================================

CONCEITO:
────────
Sistema operável 100% por teclado numérico - ideal para médicos com 
deficiência visual ou em situações onde o mouse não é prático.

ATALHOS PRINCIPAIS:
──────────────────

Teclas Globais (funcionam em qualquer tela):
  - (menos)  → Abrir menu de navegação
  / (barra)  → Ajuda e lista de atalhos
  * (vezes)  → Repetir último anúncio de áudio
  + (mais)   → Silenciar/ativar áudio

Navegação entre Módulos:
  1 → Análise de ECG
  2 → Análise de Hemograma
  0 → Voltar à tela anterior

Durante Análise:
  1, 2, 3 → Carregar exemplos clínicos
  4 → Gerar laudo
  5 → Ouvir laudo em áudio
  7 → Copiar laudo para área de transferência
  8 → Limpar formulário

EXPERIÊNCIA DO USUÁRIO:
──────────────────────
• Memorização rápida dos atalhos principais (1, 2, 3)
• Feedback auditivo confirma cada ação
• Sistema intuitivo mesmo sem visão da tela
• Possibilidade de uso com leitor de tela

📚 CASOS CLÍNICOS INCLUÍDOS (PARA DEMONSTRAÇÃO)
================================================================================

ELETROCARDIOGRAMAS:
──────────────────

1. ECG Normal
   - FC: 75 bpm
   - Ritmo sinusal regular
   - Eixo: Normal (entre 0° e 90°)
   - Intervalos normais
   - Sem alterações patológicas

2. Fibrilação Atrial
   - Ausência de ondas P
   - Resposta ventricular rápida (FC > 100 bpm)
   - Ritmo irregularmente irregular
   - QRS estreito

3. Infarto Agudo do Miocárdio Anterior
   - Supradesnivelamento do segmento ST em V1-V4
   - Ondas Q patológicas em derivações anteriores
   - Inversão de onda T
   - Laudo indica necessidade de intervenção urgente

HEMOGRAMAS:
──────────

1. Hemograma Normal
   - Todas as séries dentro dos valores de referência
   - Masculino adulto

2. Anemia Ferropriva
   - Hb: 9.5 g/dL (baixa)
   - VCM: 72 fL (microcitose)
   - RDW aumentado
   - Sugere deficiência de ferro

3. Infecção Bacteriana
   - Leucócitos: 18.000/mm³ (leucocitose)
   - Neutrófilos: 85% (neutrofilia)
   - Bastões: 12% (desvio à esquerda)
   - Compatível com processo infeccioso bacteriano

4. Plaquetopenia
   - Plaquetas: 85.000/mm³
   - Demais séries normais
   - Requer investigação de causa

5. Anemia Megaloblástica
   - Hb: 8.2 g/dL (baixa)
   - VCM: 112 fL (macrocitose)
   - Sugere deficiência de B12/folato

6. Eosinofilia
   - Eosinófilos: 12% (elevado)
   - Compatível com alergia ou parasitose
   - Investigar história clínica

7. Leucopenia Pós-Quimioterapia
   - Leucócitos: 2.800/mm³ (baixo)
   - Neutrófilos: 1.200/mm³ (neutropenia)
   - Requer precauções de infecção

8. Policitemia
   - Hb: 18.5 g/dL (elevada)
   - Ht: 58% (elevado)
   - Investigar policitemia vera vs secundária

🔍 CRITÉRIOS CLÍNICOS APLICADOS
================================================================================

ELETROCARDIOGRAMA:
─────────────────

Ritmo e Frequência:
• Classificação de ritmos (sinusal, FA, flutter, bloqueios AV)
• Bradicardia: FC < 60 bpm
• Taquicardia: FC > 100 bpm

Eixo Elétrico:
• Normal: 0° a +90°
• Desvio à esquerda: -30° a 0°
• Desvio à direita: +90° a +180°

Intervalos:
• PR normal: 120-200 ms
• QRS normal: 80-120 ms
• QTc (corrigido por Bazett): < 440 ms (homens), < 460 ms (mulheres)

Bloqueios de Condução:
• BAV de 1º grau: PR > 200 ms
• BRD: QRS > 120 ms com padrão rsR' em V1
• BRE: QRS > 120 ms com padrão em V1/V6

Isquemia/Infarto:
• Supradesnível ST ≥ 1mm: lesão aguda
• Infradesnível ST ≥ 0.5mm: isquemia subendocárdica
• Onda Q patológica: duração ≥ 40ms, profundidade > 25% do QRS
• Localização por derivações:
  - Anterior: V1-V4
  - Inferior: DII, DIII, aVF
  - Lateral: DI, aVL, V5-V6

Sobrecargas:
• Critérios de Sokolov-Lyon para HVE
• Critérios de onda P para sobrecarga atrial

HEMOGRAMA COMPLETO:
──────────────────

Série Vermelha - Valores de Referência:
• Hemácias:
  - Homens: 4.5-5.9 milhões/mm³
  - Mulheres: 4.0-5.4 milhões/mm³
• Hemoglobina:
  - Homens: 13.5-17.5 g/dL
  - Mulheres: 12.0-15.5 g/dL
• Hematócrito:
  - Homens: 41-53%
  - Mulheres: 36-46%
• VCM: 80-100 fL
• HCM: 27-33 pg
• CHCM: 32-36 g/dL
• RDW: 11.5-14.5%

Classificação de Anemias:
• Microcítica: VCM < 80 fL (ferropriva, talassemia)
• Macrocítica: VCM > 100 fL (megaloblástica, álcool)
• Normocítica: VCM 80-100 fL (perda aguda, doença crônica)

Série Branca - Valores de Referência:
• Leucócitos totais: 4.000-11.000/mm³
• Neutrófilos: 40-75% (1.800-7.700/mm³)
• Linfócitos: 20-45% (900-2.900/mm³)
• Monócitos: 3-10% (300-900/mm³)
• Eosinófilos: 1-4% (50-500/mm³)
• Basófilos: 0-2% (0-200/mm³)

Interpretação Clínica:
• Neutrofilia: infecção bacteriana, estresse, corticoides
• Linfocitose: infecção viral, leucemia linfocítica
• Eosinofilia > 5%: alergia, parasitose
• Neutropenia < 1.500/mm³: risco infeccioso aumentado

Plaquetas:
• Valor normal: 150.000-450.000/mm³
• Plaquetopenia: < 150.000/mm³
• Risco de sangramento: < 50.000/mm³
• Trombocitose: > 450.000/mm³
